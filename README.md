# onlyfun

Drop into voice rooms about anything. No sign up. No waiting. Just talk.

A real-time voice chat app where users create and join topic-based rooms on a pixel canvas. Built with Next.js, PartyKit for real-time sync, and browser WebRTC for voice.

## Getting Started

```bash
npm install
```

Create a `.env.local` file with your PartyKit host:

```
NEXT_PUBLIC_PARTYKIT_HOST=localhost:1999
```

Run the development servers:

```bash
# Next.js
npm run dev

# PartyKit (in a separate terminal)
npm run party
```

## Tech Stack

- **Next.js 15** — React framework
- **PartyKit** — real-time multiplayer server
- **Tailwind CSS** — styling
- **WebRTC** — browser voice chat
